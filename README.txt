MATIN GORY BOT Android starter project source (not a compiled APK).

Includes a dark/red Android dashboard, Guild & Glory placeholders, Bot Control information, and Settings. It does not connect to Free Fire or automate guild joins/matches. It does not request account credentials.

Build via GitHub Actions using a phone:
1. Create a GitHub repository and upload all files in this ZIP, including the hidden .github folder.
2. Open Actions and run the “Build Android APK” workflow.
3. Open the completed workflow run and download artifact “MATIN-GORY-BOT-debug-apk”.
4. Extract the artifact to get app-debug.apk. Install only if you trust the APK.
